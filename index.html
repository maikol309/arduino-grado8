Sobre el proyecto

Los estudiantes de octavo ya sabían armar circuitos, pero el código lo copiaban sin entenderlo. Este proyecto invierte el orden: primero la lógica, después el montaje. Aquí quedan las evidencias de ese recorrido.

Objetivo

Fortalecer la lógica de programación mediante el diseño de prototipos con Arduino en estudiantes de grado octavo de la Institución Educativa José Cayetano Vázquez de Ciénega, Boyacá.

Grado octavo

25 estudiantes organizados en 11 grupos de dos a cuatro integrantes, cada uno responsable de un prototipo.

Tecnología e Informática

El área donde se cruza el pensamiento computacional con el trabajo manual del taller de robótica.

Herramientas

Tinkercad Circuits para simular, Arduino UNO y protoboard para construir, y el IDE de Arduino para cargar.

Ruta de aprendizaje

Cada sesión suma un concepto nuevo de programación. Hasta ahora llevamos 5 de 6 sesiones.

  1. 0

    Diagnóstico · 31 de agosto

    Dónde estaba el vacío

    Una prueba inicial y la observación en clase mostraron que seguían instrucciones, pero no podían explicarlas.

  2. 1

    Sesión 1

    Pensar antes de programar

    Algoritmos, diagramas de flujo y la primera variable: el tiempo que controla un LED.

    int tiempo = 1000;
  3. 2

    Sesión 2

    Escuchar y responder

    Arduino lee un pulsador y responde con un LED, cada par de forma independiente.

    digitalRead(pulsador);
  4. 3

    Sesión 3

    Decidir y repetir

    if / else y ciclos for para automatizar una secuencia de seis LED.

    for (int i = 2; i <= 7; i++)
  5. 4

    Sesión 4

    Señales que cambian poco a poco

    Un potenciómetro y map() convierten valores de 0 a 1023 en una cortina de 12 LED.

    map(analogRead(A0), 0, 1023, 0, 6)
  6. 5

    Sesión 5

    Del diagrama al prototipo

    Armamos los componentes siguiendo el diagrama: servomotor, sensor ultrasónico y cómo pasar cada pin a una variable.

    miServo.attach(pinServo);
  7. 6

    Sesión 6

    Próximamente
